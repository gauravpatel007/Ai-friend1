# Scratch & Developer Diagnostic Workspace (`scratch/`)

This directory contains developer utility scripts, visual inspection tools, sandbox test artifacts, and verification screenshots generated during manual testing and debugging cycles.

---

## 📁 Directory Structure

- **`captures/`**: Preserved desktop and UI screen captures from automated verification and testing.
- **`states/`**: Diagnostic pet character state snapshots.
- **Python Scripts (`test_*.py`, `check_*.py`, `inspect_*.py`)**: Ad-hoc exploration and live diagnostic scripts for audio devices, window elevation, win32 API hooks, and UI preview captures.
- **Test Artifacts (`preview_*.db`, `preview_*.json`)**: Isolated test databases and mock settings files used during preview validation.

> [!NOTE]
> Formal, automated test suites are located in the [`tests/`](../tests/) directory.
